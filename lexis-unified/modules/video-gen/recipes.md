# Receitas prontas — Video Lexis

## Receita A — Carrossel de prints → Reel 15s

**Objetivo:** Mostrar Painel → Processos → Tarefas → Supervisao em 15 segundos.

1. Separar 4–5 prints limpos (sem dados sensiveis).
2. Roteiro (humanizer):
   - 0-3s: "Operacao de assessoria quebra quando ninguem sabe de quem e o caso."
   - 3-8s: Mostra prints com zoom leve.
   - 8-12s: "Dono do processo nao muda. Atendimento conta no ranking."
   - 12-15s: CTA "Comenta LEXIS".
3. Agnes (Image-to-Video ou Keyframes) **ou** ffmpeg Ken Burns + texto overlay.
4. Export 9:16 + 16:9.

## Receita B — Grafo da arquitetura → animacao LinkedIn

1. Abrir `graph.html` (graphify).
2. Gravar 10–15s de zoom out → zoom in em clusters importantes (Fila, Data Provider, AI Flows).
3. Overlay de texto:
   - "4.378 nos"
   - "13.547 conexoes"
   - "225 comunidades"
   - Fechar: "Nao e CRM de vitrine."
4. ffmpeg para estabilizar + legenda.

## Receita C — Demo de produto (screen recording)

1. Playwright ou OBS: login → Painel (KPIs) → abrir processo → Auditoria 3D → Supervisao.
2. Cortar partes mortas.
3. Adicionar 3–4 cartoes de texto (problema / regra / prova / CTA).
4. Musica baixa + legenda automatica (CapCut ou Whisper + ffmpeg).

## Receita D — Image-to-Video com Agnes (personagem / B-roll)

Quando precisar de movimento em cima de um print estatico:
- Subir a imagem no Agnes.
- Prompt: "slow cinematic zoom, professional legal tech dashboard, clean blue tones, subtle camera movement, no text change"
- Usar como B-roll entre os prints reais.
